# Programmation
__Objectif__

 >Être capable de comprendre le langage de programmation.

Comprendre un langage de programmation ne se limite pas à connaître sa syntaxe. Cela implique :
<ul>Lire et interpréter le code : être capable de comprendre ce que fait un programme écrit par quelqu’un d’autre.</ul>
<ul>Maîtriser les bases : variables, conditions (if, else), boucles (for, while), fonctions, etc.
Connaître les spécificités du langage : chaque langage (Python, Java, C…) a ses propres règles, bibliothèques et usages.</ul>
<ul>Écrire du code clair : utiliser des noms de variables compréhensibles et structurer son programme de façon lisible.</ul>

 >Avoir logique algorithmique

La logique algorithmique est la capacité à résoudre un problème de manière structurée et étape par étape.

<ul>Décomposer un problème : transformer un problème complexe en plusieurs sous-problèmes simples.</ul>
<ul>Construire une suite d’instructions : définir un enchaînement logique d’actions pour arriver à un résultat.</ul>
<ul>Anticiper les cas possibles : gérer les exceptions, les erreurs, ou les cas particuliers.</ul>
<ul>Optimiser les solutions : chercher la méthode la plus rapide ou la plus efficace.</ul>


 >Utiliser différents structures de données

Les structures de données permettent d’organiser et de stocker les informations efficacement.

Types simples : entiers, chaînes de caractères, booléens.
Structures classiques :
<ul>Tableaux / listes → stocker des éléments ordonnés</ul>
<ul>Piles (stack) → dernier entré, premier sorti</ul>
<ul>Files (queue) → premier entré, premier sorti</ul>
<ul>Dictionnaires / tableaux associatifs → stocker des paires clé-valeur</ul>
<ul>Choisir la bonne structure : selon le problème, certaines structures sont plus efficaces que d’autres.</ul>
<ul>Manipuler les données : ajouter, supprimer, rechercher, trier des éléments.</ul>
